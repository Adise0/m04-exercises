### What is semantics? Why does it matter?

Semantics is the term used to describe the hierarchy of the `HTML` documment. Not necessarely the tag hierarchy, but the hierarchy of contents. Separating them by relevant data, and adding the correct attributes not only helps redability for the standard user, but also for the impaired user assisting tools.

<br>

### What is an HTML Validator? Why is it important?

The validator ensures that the HTML complies with standard coding practices and specifications. Kind of a "compiler" of sorts. It ensures that the browser (or any client) can interpret the HTML.

<br>

### Where does Firefox come from, and Chrome?

Chrome is the property of Google, which comes from the `Chromium project`. An open-source project that provides the core engine of a lot of browsers and web interpreters.

Firefox instead uses it's own engine called `Quantum`. It's one of the only major browser that's not chromium-based.
